# راهنمای نصب اندیکاتور Gold RSI Strategy در MetaTrader 5

## نصب

### مرحله ۱: کپی فایل اندیکاتور

فایل `Gold_RSI_Strategy.mq5` را کپی کنید در پوشه:

```
C:\Users\[USERNAME]\AppData\Roaming\MetaQuotes\Terminal\[TERMINAL_ID]\MQL5\Indicators\
```

یا از داخل MT5:
1. منوی **File → Open Data Folder**
2. پوشه `MQL5/Indicators/` را باز کنید
3. فایل `.mq5` را در آن کپی کنید

### مرحله ۲: کامپایل

1. در MT5، کلید **F4** را بزنید تا **MetaEditor** باز شود
2. در پنل Navigator (سمت چپ)، پوشه `Indicators` را باز کنید
3. روی `Gold_RSI_Strategy.mq5` دابل‌کلیک کنید
4. کلید **F7** را بزنید (یا دکمه Compile در نوار ابزار)
5. در پنل Errors (پایین) بررسی کنید که خطایی نباشد
6. باید پیام `0 errors, 0 warnings` ببینید

### مرحله ۳: اضافه کردن به چارت

1. به MT5 برگردید
2. چارت **XAUUSD** روی تایم‌فریم **M30** باز کنید
3. از پنل Navigator (Ctrl+N):
   - پوشه `Indicators` را باز کنید
   - `Gold_RSI_Strategy` را پیدا کنید
   - آن را روی چارت drag کنید
4. پنجره تنظیمات باز می‌شود — پارامترها را تنظیم کنید (یا OK بزنید برای پیش‌فرض)

## امکانات

### روی چارت نمایش داده می‌شود:

1. **پنل اطلاعات** (گوشه بالا-راست):
   - قیمت فعلی طلا
   - مقدار RSI(30)
   - وضعیت زون (در زون ۴۰/۶۰ یا نزدیک کدام)
   - پیش‌بینی احتمالات (برگشت / واگرایی / گذشتن) برای سطح محتمل‌تر
   - نزدیک‌ترین زون دوجی با فاصله (pip و درصد)
   - تیکت ورود (وقتی RSI در زون باشد) با Entry/SL/TP/R:R
   - سشن معاملاتی

2. **زون‌های دوجی روی چارت**:
   - **مستطیل‌های نارنجی** = زون‌های هفتگی (Weekly Doji)
   - **مستطیل‌های خاکستری** = زون‌های روزانه (Daily Doji)
   - **مستطیل‌های زرد** = زونی که قیمت فعلی داخل آن است (Active)
   - هر مستطیل از open تا close کندل دوجی کشیده شده
   - برچسب با تاریخ + قیمت open/close

3. **RSI در پنجره جداگانه**:
   - خط RSI(30)
   - خطوط ۴۰ و ۶۰ با خط‌چین

### هشدارها (Alerts):

وقتی این اتفاقات رخ دهد، پیام هشدار دریافت می‌کنید:

1. **RSI وارد زون ۴۰ یا ۶۰ شد** — با احتمالات پیش‌بینی
2. **قیمت وارد زون دوجی شد** — با نوع زون (روزانه/هفتگی) و محدوده قیمت
3. **الگوی کندلی M5 تشخیص داده شد** (وقتی RSI در زون است):
   - Doji
   - Bullish/Bearish Pin Bar
   - Bullish/Bearish Engulfing
   - با جهت پیشنهادی معامله (BUY/SELL)

## تنظیمات (Input Parameters)

| پارامتر | پیش‌فرض | توضیح |
|---------|---------|------|
| RSI Period | 30 | دوره RSI |
| Oversold Level | 40 | سطح اشباع فروش |
| Overbought Level | 60 | سطح اشباع خرید |
| Zone Tolerance | 1.0 | تلورانس زون (±واحد) |
| Doji Threshold | 0.10 | آستانه دوجی (body/range) |
| Lookback Days | 90 | روز‌های اسکن برای دوجی روزانه |
| Lookback Weeks | 26 | هفته‌های اسکن برای دوجی هفتگی |
| Show Zones | true | رسم زون‌ها روی چارت |
| Show Panel | true | نمایش پنل اطلاعات |
| Enable Alerts | true | فعال‌سازی هشدار |
| Weekly Zone Color | Orange | رنگ زون هفتگی |
| Daily Zone Color | Gray | رنگ زون روزانه |

## منطق پیش‌بینی

پیش‌بینی‌ها بر اساس بک‌تست ۲ سال گذشته (۱۳۲۸ رویداد) است:

### وقتی RSI به ۴۰ یا ۶۰ می‌رسد:

| دسته | نرخ پایه |
|------|---------|
| برگشت (Reversal) | ۳۳٪ |
| واگرایی (Divergence) | ۲۱٪ |
| گذشتن (Pass-through) | ۴۶٪ |

### وقتی قیمت داخل زون مهم باشد:

| حالت | برگشت | واگرایی | گذشتن |
|------|------|--------|------|
| خارج از زون | ۳۳٪ | ۲۰٪ | ۴۷٪ |
| داخل یک زون | ۳۳٪ | ۲۳٪ | ۴۴٪ |
| داخل هر دو زون | ۴۱٪ | ۳۱٪ | **۲۸٪** |

### زون‌های مهم (دوجی):
- کندل‌های روزانه و هفتگی که body ≤ ۱۰٪ range باشند
- Open و Close آنها به‌عنوان سطوح حمایت/مقاومت در نظر گرفته می‌شود
- فقط زون‌هایی که قبل از زمان فعلی شکل گرفته‌اند (احترام به علیت)

## نکات مهم

1. **تایم‌فریم**: این اندیکاتور باید روی چارت **M30** نصب شود
2. **سمبل**: روی **XAUUSD** (طلای اسپات) کار می‌کند
3. **به‌روزرسانی**: هر ۳۰ ثانیه زون‌ها و پنل به‌روزرسانی می‌شوند
4. **کوچک‌نمایی چارت**: برای دیدن زون‌های دورتر، چارت را کوچک کنید (Zoom Out)
5. **حذف اندیکاتور**: راست‌کلیک روی پنل → Delete Indicator

## خطایابی

### خطای کامپایل:
- مطمئن شوید MT5 Build 3000+ دارید
- MetaEditor را آپدیت کنید

### زون‌ها نمایش داده نمی‌شوند:
- `Show Zones` را در تنظیمات `true` بگذارید
- چک کنید داده تاریخچه XAUUSD کافی باشد (حداقل ۹۰ روز)

### هشدارها کار نمی‌کنند:
- `Enable Alerts` را `true` کنید
- در MT5: Tools → Options → Notifications → Enable Alerts

### پنل نمایش داده نمی‌شود:
- `Show Panel` را `true` کنید
- مطمئن شوید فضای کافی در گوشه راست-بالا وجود دارد
